How this page is built / Cómo está hecha esta página

APP_CONFIG — InjectionToken<AppConfig>
Holds the real PokeAPI base URL. Provided once, in app.config.ts. Guarda la URL base real de PokeAPI. Se provee una sola vez, en app.config.ts.
pokeApiErrorInterceptor — HttpInterceptorFn
Runs on every HTTP call from this app; turns a 404 into a friendly "doesn't exist" message before it reaches the service. Corre en cada llamada HTTP de esta app; convierte un 404 en un mensaje amigable antes de que llegue al servicio.
PokemonService — @Injectable({{ '{' }} providedIn: 'root' {{ '}' }})
Injects HttpClient + APP_CONFIG, builds the URL, returns the Observable — never subscribes itself. Inyecta HttpClient + APP_CONFIG, arma la URL, regresa el Observable — nunca se suscribe.
PokemonDemo (this component / este componente)
The one that subscribes, and owns the loading/error/data signals you're looking at right now. El que se suscribe, y es dueño de las signals de carga/error/data que estás viendo ahora mismo.
